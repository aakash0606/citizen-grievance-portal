1) Who uses this app?
    Citizens who want to file a complaint, and Officers who are responsible for resolving them.

2) What can a Citizen do?
    Register/Login, File a new grievance (title + description), View list of their own grievances, Track status of a specific grievance.

3) What can an Officer do?
    Login, View grievances assigned to their department, Update the status of a grievance (e.g. Pending → In Progress → Resolved).

4) What happens automatically?
    When a grievance is filed, it gets auto-categorized (e.g. water/roads/electricity) based on keywords, and auto-assigned to the right department. If a grievance stays unresolved beyond a set number of days, it gets auto-flagged as 'Escalated'.

5) What am I NOT building right now?
    No SMS/email notifications, No payment system, No mobile app (web-only), No AI/ML — just simple rule-based logic. This protects you from scope creep later git
